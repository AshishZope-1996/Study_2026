# Python Notes

## 1. Data Engineering Basics
- Use Python for ETL, file handling, API calls, and automation.
- Common libraries: `pandas`, `requests`, `json`, `os`, and `pathlib`.
- Keep scripts modular and readable for production use.

## 2. Interview Focus
- Explain how you handle missing values and clean messy data.
- Show how you structure reusable functions and maintainable code.
- Mention logging, error handling, and testing as strong engineering practices.

## 3. Best Habits
- Use virtual environments for project isolation.
- Write small debug-friendly code blocks.
- Document assumptions and data transformations clearly.
