# SQL Notes

## 1. Core Concepts
- Use `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, and `ORDER BY` to shape data.
- `JOIN` combines related tables; prefer indexes on join keys.
- `COUNT(*)`, `SUM()`, `AVG()`, and `MIN()/MAX()` are essential analytics functions.

## 2. Interview Tips
- Explain the difference between `INNER JOIN` and `LEFT JOIN` clearly.
- Mention window functions like `ROW_NUMBER()`, `RANK()`, and `SUM() OVER()` for advanced analysis.
- Optimize queries with selective filters and proper indexing.

## 3. Practice Checklist
1. Write a join query from two tables.
2. Use `GROUP BY` with aggregate functions.
3. Solve a ranking problem using window functions.
