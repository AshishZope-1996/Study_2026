
# SQL Interview Paper (Intermediate to Advanced). 


## Section A – Ranking & Aggregation.

1. Write an SQL query to fetch the **second highest salary** from the `Employee` table.
2. Write an SQL query to fetch the **second highest salary in each department**.
3. Write an SQL query to find the **top-paid employee in each department**.
4. Write an SQL query to find the **top 3 highest-paid employees in each department**.
5. Write an SQL query to find employees whose salary is **higher than the average salary of their department**.
6. Write an SQL query to find employees whose salary is **lower than the average salary of their department**.
7. Write an SQL query to calculate the **average salary for each department**.
8. Write an SQL query to find the department having the **highest average salary**.

## Section B – Joins & Self Joins.

9. Write an SQL query to find employees who earn **more than their manager**.
10. Write an SQL query to display each employee along with their manager's name.
11. Write an SQL query to find employees who **do not have a manager**.
12. Write an SQL query to find managers who have **more than five employees reporting to them**.

## Section C – Window Functions.

13. Write an SQL query to assign **Rank, Dense Rank, and Row Number** based on salary within each department.
14. Write an SQL query to fetch the **third highest salary** in each department.
15. Write an SQL query to identify employees having **duplicate salaries** within the same department.

## Section D – Group By & Having.
16. Write an SQL query to find departments having **more than 10 employees**.
17. Write an SQL query to find departments where the **average salary exceeds ₹100,000**.
18. Write an SQL query to count the number of employees in each department.

## Section E – Advanced SQL
19. Write an SQL query to find employees whose salary is **greater than the salary of all employees in the Sales department**.
20. Write an SQL query to find the employee(s) with the **highest salary without using `MAX()`**.
21. Write an SQL query to fetch the **Nth highest salary**, where **N** is provided as an input parameter.
22. Write an SQL query to find employees who have the **same salary as another employee**.
23. Write an SQL query to find employees whose salary is **between the department average salary and the department maximum salary**.
24. Write an SQL query to find the **department-wise salary difference** between the highest-paid and lowest-paid employee.
25. Write an SQL query to identify departments where **all employees earn more than ₹50,000**.
26. Write an SQL query to display the **salary percentage contribution** of each employee within their department.
27. Write an SQL query to find employees who joined **before their manager**.
28. Write an SQL query to find employees who share the **same manager and the same salary**.
29. Write an SQL query to find employees who have the **longest tenure** in each department.
30. Write an SQL query to display the **salary trend** by assigning salary bands (Low, Medium, High) using a `CASE` statement.

1. Find customers who have never placed an order.

3. Find duplicate records from a table.
4. Delete duplicate records while keeping the latest record.
5. Find consecutive duplicate values.
6. Find the latest record for each employee.
7. Find employees who joined in the last 30 days.
8. Find departments without any employees.
9. Swap values of two columns without using a temporary variable.
10. Find the second most recent order for each customer.
11. Calculate a running total of salary by department.
12. Find missing IDs in a sequence.
13. Pivot employee salaries department-wise.
14. Unpivot department columns into rows.
