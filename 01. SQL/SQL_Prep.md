SQL

1. What is SQL?
   1. SQL (Structured Query Language) is a standard programming language used to manage and manipulate relational databases. It allows users to create, read, update, and delete data, as well as define database structures and control access to the data.
2. Types of SQL Command
   1. ddl : create, drop, truncate, alter, rename
   2. dml : insert, update, delete
   3. dql : select
   4. dcL : grant, revoke
   5. tcl : begin, commit, rollback, savepoint, set transaction
